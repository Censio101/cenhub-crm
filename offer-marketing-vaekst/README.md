# Marketing Vækstpakke, JSV BYG ApS

Statisk, redaktionel tilbudsside for Censio (React + Vite + TypeScript).

## Kør lokalt

```bash
cd offer-marketing-vaekst
pnpm install   # eller npm install
pnpm dev       # http://localhost:5173
```

## Byg

```bash
pnpm build
```

Output i `dist/`, kan hostes som statiske filer.
